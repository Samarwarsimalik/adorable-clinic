ADORABLE CLINIC — STATIC HTML REDESIGN

Included
- index.html (homepage)
- hair.html
- skin.html
- laser.html
- anti-aging.html
- dermatology.html
- about.html
- contact.html
- treatment.html (dynamic treatment detail page using query string)
- privacy.html and terms.html placeholders
- responsive CSS and vanilla JavaScript
- local Pexels images
- WhatsApp appointment request flow (no backend required)

How to run
1. Extract the ZIP.
2. Double-click index.html, or upload the folder to any static host.
3. For the most consistent local behaviour, run a tiny local server:
   python -m http.server 8000
   Then visit http://localhost:8000

Important before production
- Verify phone, email, branch addresses and opening hours.
- Replace legal placeholders with reviewed Privacy Policy and Terms.
- Review every treatment description with a qualified clinician.
- Add real, consented clinic photos if you want to replace stock photography.
- If you want form submissions stored in a database/CRM, connect a backend or form service.

No React, WordPress, PHP or framework is used.
